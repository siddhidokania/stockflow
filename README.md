# StockFlow: Inventory and Order Management System

StockFlow is a full-stack web app for managing products, customers, and orders, with stock levels that update automatically as orders are placed or cancelled. It has a React frontend, a FastAPI REST backend, and a PostgreSQL database, and the whole stack runs with a single `docker compose up`.

## Features

- **Products:** create, update, and delete products with a unique SKU, price, category, and stock quantity.
- **Customers:** manage customers with unique email validation.
- **Orders:** create multi-item orders. The backend checks stock, deducts it in one transaction, and calculates the order total. Cancelling an order restores the stock.
- **Dashboard:** totals for products, customers, orders, and revenue, plus low-stock alerts.
- **API docs:** interactive Swagger UI at `/docs`, generated by FastAPI.

## Architecture

```
React (Nginx, :3000)  ──►  FastAPI + Uvicorn (:8000)  ──►  PostgreSQL 16 (:5432)
```

## Data Model

```
customers (1) ──< orders (1) ──< order_items >── (1) products
```

| Table | Key columns |
|---|---|
| `products` | `id`, `name`, `sku` (unique), `price`, `quantity`, `category` |
| `customers` | `id`, `full_name`, `email` (unique), `phone`, `address` |
| `orders` | `id`, `customer_id` (FK), `status`, `total_amount`, `created_at` |
| `order_items` | `id`, `order_id` (FK), `product_id` (FK), `quantity`, `unit_price`, `subtotal` |

## Run Locally

You need [Docker](https://docs.docker.com/get-docker/) installed.

```bash
git clone https://github.com/siddhidokania/stockflow.git
cd stockflow/inventory-app
cp .env.example .env
docker compose up --build
```

| Service | URL |
|---|---|
| Frontend | http://localhost:3000 |
| Backend API | http://localhost:8000 |
| API docs (Swagger) | http://localhost:8000/docs |

## API Endpoints

| Resource | Endpoints |
|---|---|
| Products | `GET /products/`, `POST /products/`, `GET /products/{id}`, `PUT /products/{id}`, `DELETE /products/{id}` |
| Customers | `GET /customers/`, `POST /customers/`, `GET /customers/{id}`, `DELETE /customers/{id}` |
| Orders | `GET /orders/`, `POST /orders/`, `GET /orders/{id}`, `DELETE /orders/{id}` (cancels and restores stock) |
| Dashboard | `GET /dashboard/` |
